PROJECT TITLE : La Falaise Hotel Reservation System
DESCRIPTION: A web based hotel reservation system developed for LaFalaise Hotel.
The system allows visitors to explore the hotel, view available rooms and services, 
check room information and make reservations through a user friendly interface
OBJECTIVES: Provide customers with an easy way to explore LaFalaise Hotel
Display available rooms and their informations
Allow visitors to make room reservations 
Display the hotel's location using an interactive map
FEATURES: 
Hotel information:View information about the hotel, learn about the hotel's facilities and services
Room Management:view available rooms,display room categories, display room prices
Reservations:select reservation dates, select number of guests, make room reservations, store reservation information in the database
Hotel Services: Explore food and drink services, view other services offerred by the hotel
Location: view hotel's interactive map.
Contact: view hotel contact information and access the hotel's location and other relevant information
Languages Used
Frontend: REACT, TAILWINDCSS
BACKEND:PHP
DATABASE:MySql
